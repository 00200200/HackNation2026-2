{doc2json}

PDF-y sprawy KIO na JSON w schemacie UZP.

Upuść PDF-y sprawy

Odwołanie, pełnomocnictwo, przelew. W dowolnej kolejności.

    odwolanie.json Przykład 

    {
  "OdwolanieKIO": {
    "data": "2026-03-14",
    "miejscowosc": "Gdańsk"
  },
  "Odwolujacy": [{
    "nazwa": "Alfa Budowa sp. z o.o.",
    "krs": "0000123456",
    "nip": null
  }],
  "ZamowieniePubliczne": {
    "numer_bzp": "2026/BZP00012345"
  }
}

    Po prawej przykład z fikcyjnymi danymi.

    Problem

    Sprawa odwoławcza to kilka PDF-ów o różnej budowie, często skanów. Człowiek je czyta bez trudu, system nie.

    • Kilka plików na sprawę
    • Każdy ułożony inaczej
    • Część to skany

    Na podstawie opisu wyzwania Odwołania2json, UZP, HackNation 2026.

    1. Wrzuć

      Wszystkie PDF-y sprawy, także skany.

    2. Rozpoznajemy

      Rodzaj dokumentu z treści, nie z nazwy.

    3. Pobierz

      JSON dla każdego pliku. Brak danej to null.
