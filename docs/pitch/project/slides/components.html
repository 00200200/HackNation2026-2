Regulamin w § 4 ust. 1 wymaga, żeby rozwiązania zewnętrzne były wyraźnie wskazane w prezentacji, więc wymieniamy je tutaj. Biblioteki i modele są open source, a jedyną usługą zewnętrzną jest opcjonalne API Mistral AI. OCR robi Tesseract z polskimi i angielskimi modelami tessdata_fast, które dołączamy do repozytorium; RapidOCR z modelami PP-OCRv6 domyślnie czyta pieczęcie zarządu na jednostronicowych skanach pełnomocnictw, a w trybie hybrydowym daje drugi odczyt skanu. Tekst z PDF czyta pdfplumber, strony do OCR renderuje PDFium. Morfeusz 2 sprowadza nazwiska do mianownika, python-stdnum sprawdza sumy kontrolne NIP, REGON i PESEL, Babel czyta kwoty, asn1crypto czyta certyfikaty podpisów w PDF. GUI to Shiny, API to FastAPI. Model językowy jest opcjonalny i domyślnie wyłączony; profil z Ministral 3B korzysta z pydantic-ai i SDK openai.
