Pokaz trwa dwie minuty, scenariusz z komendami jest w docs/pitch/demo.md. Najpierw CLI na folderze z całą sprawą z danych UZP, dokumentem spoza klas i dwoma skanami: program wypisuje klasę każdego pliku, a skan odwołania wychodzi identyczny ze wzorcem UZP. Potem ten sam folder w GUI: strona PDF po lewej, JSON po prawej, wyniki do pobrania jako ZIP. Na koniec kopiujemy plik TOML zgłoszenia przystąpienia do katalogu klas i klikamy Analizuj jeszcze raz; GUI pokazuje też frazy, które wybrały klasę. Gdyby GUI zawiodło, ten sam krok robimy w CLI.
