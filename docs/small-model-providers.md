**Mistral processing location.** Mistral AI is registered in Paris, France. For a region-pinned request the OpenAI-compatible base is `https://api.eu.mistral.ai/v1`. The regional docs guarantee a selected geography for model execution, list “EU and EFTA countries,” and give the default global hostname no location commitment. Switzerland belongs to EFTA and is outside the EEA. The general help page says data is hosted by default in the EEA and flags feature-specific transfers. The regional geography table leaves the exact country for this model open. A strict EU/EEA-only submission therefore needs a narrower assurance covering the chosen deployment. The region may handle inference while account configuration, billing and analytics go elsewhere. The authenticated regional `GET /v1/models` is the availability check for the pinned model. Use stateless chat completions with local images or text as appropriate. Regional endpoints do not offer Files, Batch or Agents. [Legal identity and privacy](https://legal.mistral.ai/terms/privacy-policy/) · [Regional inference](https://docs.mistral.ai/inference/regional-inference) · [General storage guidance](https://help.mistral.ai/en/articles/347629-where-do-you-store-my-data-or-my-organization-s-data) · [EEA membership](https://www.efta.int/about-efta/faqs)

**Mistral billing and key.** Create or sign into a Mistral account, open the Studio workspace, activate billing and pay-as-you-go, open API Keys, select New key, give it a name and expiry, then copy it once. Mistral estimates five minutes for key setup. The billing manual says Free mode covers Studio trials and requires billing activation for the API. The Help Center separately describes free API rate limits. Budget this run as paid and verify the organization's actual limits in Admin. No universal free API credit amount or fixed request quota was established. [API key quickstart](https://docs.mistral.ai/getting-started/quickstarts/studio/activate-and-generate-api-key) · [Billing manual](https://docs.mistral.ai/admin/billing-usage/usage-limits) · [Help Center limits](https://help.mistral.ai/en/articles/698531-why-am-i-hitting-api-rate-limits-and-how-do-i-increase-them)

**Mistral content handling.** Studio Free permits training on inputs and outputs. Mistral documents an API-specific training opt-out for customers, including pay-as-you-go. Disable Anonymous improvement data in Admin → Privacy and verify the organization setting. The standard API privacy policy describes rolling 30-day abuse monitoring. Zero data retention requires pay-as-you-go and explicit approval for stateless endpoints including chat completions. The training and retention controls are independent. The published DPA governs processing for a business customer and allows covered international transfers under the specified safeguards. **Ollama Cloud catalog check.** I fetched the public hosted tag index and requested metadata via `POST /api/show` for each of its 24 tags. Twenty-three returned positive counts. The smallest of those was GPT-OSS 20B. The one unspecified count was MiniMax-M3, documented at 428B. Additional targeted requests for `gemma4:e2b`, `gemma4:e4b`, `qwen3.5:4b`, and `qwen3:4b` returned 404. `ministral-3:3b` and `ministral-3:8b` returned 410. Ollama says cloud inference runs primarily in the US with European overflow, processes prompts transiently and never trains on them. Its public endpoints establish neither a small cloud model nor EU/EEA residency. **Candidate.** For native image input or local OCR followed by schema-constrained extraction, prioritize `ministral-3b-2512` on an EU/EEA-qualified deployment.
