How a PDF becomes JSON

The CLI, the desktop viewer and doc2json.pl share one pipeline: kio2json.pipeline

1

Read

pdfplumber reads the first pages. Pages without text go through Tesseract OCR at 300 dpi.

2

Route

Each class in config/classes/*.toml checks the text. First match wins.

3

Extract

Rule extractors rebuild party blocks and receipt columns from word positions.

4

Normalise

ISO dates, BZP and TED formats, the action code dictionary, checksum-checked account numbers.

5

Write

One JSON per PDF, same name. Anything else gets an empty file.

Optional model engine. With an endpoint configured, a document the rules reject is routed by a language model. Every accepted value must cite a supporting span of the source text.
